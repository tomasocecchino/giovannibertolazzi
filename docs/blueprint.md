# **App Name**: Bertolazzi Music

## Core Features:

- Navigation Bar: Horizontal navigation bar for easy access to all sections.
- Concert Listing: Display upcoming concert list with dates, locations, and ticket links.
- Discography Display: Showcase discography with album covers and links to purchase/stream.
- Media Gallery: Image and video gallery for media content.
- Contact Information: Contact section with email, phone numbers, and social media links.
- News Feed: News section to post recent articles, interviews, and updates.
- AI Concert Recommender: Use an AI tool to generate personalized concert recommendations based on user preferences and location, where the recommendations might include considering the user's past concert attendance, known location and musical tastes, or information derived from similar users' listening habits.

## Style Guidelines:

- Primary color: Dark blue (#004165) for background and main titles, providing a sophisticated and musical feel.
- Background color: Very light blue (#F0F8FF), close to white but ever-so-slightly differentiated for contrast.
- Accent color: Light blue (#008DDA) for buttons, links, and secondary details, creating visual interest and call to action.
- Body and headline font: 'Clash Display' (sans-serif) for a modern, consistent look.
- Use minimalist icons in light blue (#008DDA) for navigation and key sections.
- Responsive layout adapting to various screen sizes, ensuring mobile-friendliness.
- Subtle animations for image loading and page transitions, enhancing user experience.
